
# 🛒 Digital Market Bot

Un bot Telegram intelligent conçu pour **Digital Market**, permettant aux clients de découvrir des produits, de passer des commandes et de gérer les interactions directement via Telegram.

---

## 🚀 Fonctionnalités
- **Accueil personnalisé :** Message de bienvenue interactif pour chaque utilisateur (`/start`).
- **Catalogue de produits :** Consultation facile des articles disponibles.
- **Gestion des commandes :** Processus de commande fluide et automatisé.
- **Panneau d'administration :** Outils dédiés pour les administrateurs pour gérer les produits et suivre l'activité.

---

## 🛠️ Technologies utilisées
- **Python 3.x**
- **python-telegram-bot** (Bibliothèque pour l'API Telegram)
- **Hébergement :** Compatible Railway / Render
